# 04 — Sistema visual inicial (pre UX/UI final)

Este sistema es deliberadamente simple. La Fase 7 puede cambiar detalles sin romper las funciones.

## Paleta

- `ink-950`: `#08080B` — fondo principal.
- `ink-900`: `#111116` — superficies.
- `ink-800`: `#1B1B22` — bordes/superficies elevadas.
- `rose-500`: `#E83E78` — acción principal.
- `rose-700`: `#A6164F` — estados profundos.
- `rose-200`: `#F7B8CF` — detalles suaves.
- `white`: `#F7F7F8` — texto principal.
- `muted`: `#A7A7B0` — texto secundario.

## Reglas

- Nada de degradados como elemento dominante.
- Rosa reservado para CTA, links activos, tags y pequeños acentos.
- Cards con borde sutil, no sombras grandes.
- Radios moderados (10–16 px), no todo en píldoras.
- Motion solo para menú, focus/hover y feedback de interacción.
- Imágenes finales: propias de LEAD UNMSM o prensa/autorizadas.

## Tipografía

Inicialmente se usa la pila del sistema para evitar cargar fuentes. En Fase 7 se puede adoptar la tipografía oficial si existe licencia y archivos aprobados.
