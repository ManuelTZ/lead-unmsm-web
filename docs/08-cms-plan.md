# 08 — Plan de CMS / edición no técnica

## Fase MVP
No CMS. Contenido local tipado para evitar dependencia prematura.

## Fase 6 recomendada
Sanity por facilidad editorial y contenido estructurado.

### Tipos de contenido
- Evento
- Noticia
- Miembro
- Métrica de impacto
- Aparición en prensa
- Aliado

### Permisos deseados
- Comunicaciones: Noticias, Prensa.
- Eventos: Eventos.
- Dirección: Métricas, Aliados, Equipo.
- Programador: esquemas, integraciones, diseño y deploy.

## Alternativa de costo/dependencias
CMS basado en Git si el equipo acepta una experiencia editorial más técnica y quiere mantener el contenido dentro del repositorio.

## Regla de migración
Nunca migrar todos los tipos a la vez. Evento primero, luego Noticia, después el resto.
