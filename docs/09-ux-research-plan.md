# 09 — Plan de UX/UI (Fase 7)

## Objetivo

Rediseñar después de validar funciones, no antes.

## Participantes recomendados

- 5–8 estudiantes de perfiles/ciclos distintos.
- 2 personas que no conozcan LEAD.
- 1–2 personas con perspectiva de empresa/institución si la landing de alianzas es prioritaria.

## Tareas de prueba

1. “Encuentra el próximo evento y dime cómo te inscribirías”.
2. “Descubre qué área podría encajar contigo”.
3. “Encuentra una noticia sobre tecnología”.
4. “Explícame qué hace LEAD UNMSM después de mirar la web 30 segundos”.
5. Empresa: “¿Dónde irías para proponer una alianza?”.

## Señales a observar

- tiempo hasta encontrar el CTA correcto.
- errores o retrocesos.
- palabras de navegación que no entienden.
- si confunden noticias con eventos.
- si el estilo comunica seriedad + juventud sin parecer un clon de otro chapter.

## Iteración visual

1. Wireframes en escala de grises.
2. Validar arquitectura/jerarquía.
3. Aplicar tipografía y spacing.
4. Integrar rosa/negro.
5. Integrar logo oficial.
6. Integrar fotografía real.
7. Reejecutar E2E.
8. Prueba manual móvil/teclado.

## Criterio de salida

El rediseño no puede cerrar una fase si rompe una prueba funcional previamente verde.
