# Brand assets

El usuario confirmó que el **isotipo de LEAD es universal entre chapters** y autorizó reutilizarlo desde el referente suministrado.

## Assets activos

- `lead-mark.webp` — isotipo LEAD optimizado para la web; usar por defecto.
- `lead-mark.png` — fallback PNG / usos donde WebP no convenga.
- `favicon.png` — derivado optimizado para navegador.

## Regla de chapter

El archivo de referencia `logo-lead-uni.png` incluye el texto específico **UNI**, por lo que no se usa como wordmark completo de LEAD UNMSM. En la interfaz se combina el isotipo universal con texto HTML `LEAD` + `UNMSM` para no mezclar chapters y mantener accesibilidad/responsividad.

Si posteriormente se recibe un wordmark oficial `LEAD UNMSM`, puede sustituirse en una tarea aislada sin cambiar los flujos funcionales.

No subir archivos de fuente si no existe licencia clara para redistribuirlos.
