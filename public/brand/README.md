# Brand assets

El usuario confirmó que los archivos activos de esta carpeta son los **logos oficiales disponibles de LEAD UNMSM**. El isotipo de LEAD es universal entre chapters.

## Assets activos

- `lead-mark.webp` — isotipo LEAD optimizado para la web; usar por defecto.
- `lead-mark.png` — fallback PNG / usos donde WebP no convenga.
- `favicon.png` — derivado optimizado para navegador.
- `social-share.png` — composición editorial original generada con la herramienta integrada de ImageGen para vistas previas Open Graph; no representa un logo oficial y debe mantenerse por debajo de 750 KB.

## Regla de chapter

El archivo de referencia `logo-lead-uni.png` incluye el texto específico **UNI**, por lo que no se usa como wordmark completo de LEAD UNMSM. En la interfaz se combina el isotipo universal con texto HTML `LEAD` + `UNMSM` para no mezclar chapters y mantener accesibilidad/responsividad.

Si posteriormente se recibe un wordmark oficial `LEAD UNMSM`, puede sustituirse en una tarea aislada sin cambiar los flujos funcionales.

La imagen social evita texto y emblemas inventados. Usa la paleta carbón/rosa del prototipo y puede reemplazarse por una pieza fotográfica propia o un key visual oficial cuando el chapter lo apruebe.
